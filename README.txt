DOBUNZA — FIXED THEME TOGGLE

Cara menggunakan:
1. Ekstrak folder ZIP ini.
2. Salin index.html, style.css, dan script.js ke folder proyek Dobunza kamu, timpa file kode lama jika diminta.
3. Pertahankan folder aset yang sudah kamu punya (images/, music/, dan aset lainnya) di folder proyek yang sama.
4. Buka index.html di browser, lalu tekan Ctrl+F5.

Catatan: ZIP ini berisi tiga file kode yang kamu unggah. Folder foto dan musik tidak ikut karena tidak ada di unggahan awal; jangan hapus folder aset dari proyek lama. Tombol tema sudah dipindah ke luar elemen nav dan CSS penempatannya ditambahkan di bagian paling akhir agar mengalahkan aturan lama yang bertentangan.
