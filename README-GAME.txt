DOBUNZA — OUR LITTLE ADVENTURE (ONLINE 2 PLAYER)

CARA MEMASANG
1. Ekstrak ZIP ini ke folder baru, atau salin file-file di dalam folder Dobunza-Fixed ke folder proyek Dobunza yang sekarang. Jangan menghapus folder foto/musik milikmu.
2. Pastikan index.html, style.css, script.js, game.html, game.css, dan game.js berada di folder yang sama.
3. Buka folder proyek di VS Code.
4. Jalankan index.html menggunakan ekstensi Live Server (klik kanan index.html > Open with Live Server).
5. Pilih menu "Our Games ♡" di navbar, atau buka game.html.

CARA MAIN BERSAMA LEWAT INTERNET
1. Kedua pemain harus membuka game.html dari situs yang sama melalui Live Server atau hosting HTTPS dan internet aktif.
2. Pemain pertama klik "Buat Room".
3. Bagikan kode room yang muncul kepada pemain kedua.
4. Pemain kedua memasukkan kode tersebut lalu klik "Gabung".
5. Setelah status terhubung, gerakkan karakter untuk mengumpulkan 12 hati.

KONTROL
- Laptop: WASD atau tombol panah untuk bergerak, SPACE untuk melompat.
- HP: tombol arah dan tombol LOMPAT di bawah arena; mode lanskap disarankan.
- Semak dan batu menghalangi jalan saat berjalan biasa. Lompat untuk melewatinya sambil mengumpulkan 12 hati.

CATATAN PENTING
- Fitur online memakai PeerJS dan layanan signaling publik PeerJS melalui CDN, sehingga internet dan akses ke layanan pihak ketiga diperlukan. Layanan publik tidak dijamin selalu tersedia.
- Live Server cocok untuk uji coba lokal, tetapi untuk dua perangkat berbeda gunakan hosting HTTPS atau jaringan yang bisa diakses kedua perangkat. Membuka file HTML langsung (file://) tidak disarankan.
- Ini prototipe multiplayer ringan, tanpa akun, penyimpanan skor permanen, atau server pribadi. Kode room bersifat sementara.
- File game ditambahkan sebagai fitur terpisah. Fitur website utama dan dashboard admin tetap disertakan.


MODE SOLO RUNNER (PEMBARUAN)
- Pilih "Main Sendiri" untuk memainkan runner side-scrolling.
- Tekan SPACE atau panah atas untuk melompat di laptop.
- Di HP, gunakan tombol LOMPAT.
- Hindari semak, kristal, jamur, dan tunggul kayu. Menabrak rintangan berarti gagal.
- Kumpulkan 12 hati sepanjang lintasan dan capai gerbang FINISH.
- Tekan "Coba lagi" setelah gagal atau "Main lagi" setelah menang untuk mengulang.
- Lintasan bergerak horizontal jauh; arena tetap berukuran layar seperti game Chrome Dino.
